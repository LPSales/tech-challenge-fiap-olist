# Tech Challenge FIAP - Fase 1
## Análise de Dados do Marketplace Olist

### 1. Sobre o projeto

Este projeto foi desenvolvido como parte do Tech Challenge da Pós-Graduação em Data Analytics da FIAP.

O objetivo é analisar o desempenho do marketplace Olist a partir de dados históricos de vendas, buscando identificar padrões de crescimento, previsibilidade comercial e fatores que podem representar riscos ou oportunidades para o negócio.

A análise considera a perspectiva de investidores e gestores, com foco na sustentabilidade do crescimento e na eficiência operacional.

### 2. Problema de negócio

O crescimento histórico de um marketplace é suficiente para indicar uma operação sustentável e previsível?

Para responder a essa questão, foram investigados indicadores comerciais, comportamento das vendas e fatores logísticos que podem impactar a experiência dos consumidores.

### 3. Principais frentes de análise

- **Crescimento comercial:** evolução dos pedidos e do GMV ao longo do tempo.
- **Previsibilidade:** análise da estabilidade das vendas e da variação mensal.
- **Desempenho logístico:** avaliação dos prazos de entrega e dos atrasos.
- **Experiência do cliente:** relação entre atrasos e avaliações dos pedidos.
- **Riscos e oportunidades:** identificação de fatores que podem comprometer o crescimento sustentável.

### 4. Base de dados

Foi utilizado o Brazilian E-Commerce Public Dataset by Olist, disponibilizado publicamente no Kaggle.

A base reúne informações sobre pedidos, clientes, produtos, vendedores, pagamentos, entregas e avaliações.

### 7. Objetivo final

Transformar dados históricos em informações estratégicas que apoiem a tomada de decisão, permitindo avaliar o crescimento, a previsibilidade comercial e os riscos operacionais de um marketplace.
